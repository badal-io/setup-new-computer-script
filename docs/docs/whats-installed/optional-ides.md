# Optional IDEs and Tools

The setup script provides an interactive menu that allows you to select optional Integrated Development Environments (IDEs) and other development tools for installation.

These are installed via Homebrew Cask if selected.

## The Options

### Visual Studio Code

- **Website:** [https://code.visualstudio.com/](https://code.visualstudio.com/)

A lightweight but powerful source code editor that runs on your desktop and is available for Windows, macOS and Linux. It comes with built-in support for JavaScript, TypeScript and Node.js and has a rich ecosystem of extensions for other languages and runtimes.

### JetBrains Toolbox

- **Website:** [https://www.jetbrains.com/toolbox-app/](https://www.jetbrains.com/toolbox-app/)

The JetBrains Toolbox App is a control panel that allows you to manage all of your JetBrains IDEs, projects, and settings from a single location. If you use multiple JetBrains products (like IntelliJ, PyCharm, and GoLand), this is the recommended way to install and keep them updated.

### PyCharm

- **Website:** [https://www.jetbrains.com/pycharm/](https://www.jetbrains.com/pycharm/)

The professional Python IDE by JetBrains. It provides a comprehensive set of tools for Python development, including an intelligent code editor, debugger, and support for major web development frameworks.

### GoLand

- **Website:** [https://www.jetbrains.com/go/](https://www.jetbrains.com/go/)

The Go IDE by JetBrains. It offers excellent code completion, error detection, and debugging tools specifically for the Go language.

### WebStorm

- **Website:** [https://www.jetbrains.com/webstorm/](https://www.jetbrains.com/webstorm/)

A powerful IDE for modern JavaScript and TypeScript development. It provides advanced support for popular frameworks like React, Vue.js, and Angular.

### Sublime Text

- **Website:** [https://www.sublimetext.com/](https://www.sublimetext.com/)

A sophisticated text editor for code, markup, and prose. It's known for its speed, simplicity, and powerful plugin ecosystem.

### iTerm2

- **Website:** [https://iterm2.com/](https://iterm2.com/)

iTerm2 is a replacement for the default Terminal app on macOS. It offers a wide range of features to improve your command-line workflow, including split panes, search, and extensive customization.
