# Applications

The script automates the installation of several common desktop applications that are essential for development and productivity. All applications are installed via Homebrew Cask.

## Browsers

### Firefox

- **Installed via:** `brew install --cask firefox`

Mozilla Firefox is a popular, open-source web browser with strong privacy features and powerful developer tools.

### Google Chrome

- **Installed via:** `brew install --cask google-chrome`

Google Chrome is the most widely used web browser and a critical tool for web development, debugging, and testing. The script also applies a few tweaks to Chrome's settings (see [System Tweaks](./system-tweaks.md)).

## Development Tools

### Docker Desktop for Mac

- **Installed via:** `brew install --cask docker`

Docker Desktop is an application for building and sharing containerized applications. It provides a complete development environment that includes Docker Engine, Docker CLI, and Kubernetes. It's an essential tool for creating reproducible development and production environments.

### Postman

- **Installed via:** `brew install --cask postman`

Postman is a popular application for API development. It allows you to design, build, test, and document APIs with an easy-to-use graphical interface.
