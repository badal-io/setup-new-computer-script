# Badal-IO Specific Setup

This setup script includes a dedicated section for installing tools and configurations that are specific to the development environment at Badal-IO.

This is handled by the `badal-io.sh` script, which is automatically called from the main setup script.

## What's Installed

The following tools are installed:

- **Terraform**: The infrastructure-as-code tool from HashiCorp, used for managing cloud resources.
- **Vault CLI**: The command-line interface for HashiCorp Vault, used for managing secrets.
