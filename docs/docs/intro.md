# Introduction

This documentation provides a comprehensive guide to the `setup-new-computer-script`, a set of shell scripts designed to automate the setup of a new developer's computer on macOS.

The primary goals of this documentation are to:

- Make the setup process as clear and straightforward as possible.
- Provide a detailed reference for every tool, application, and configuration applied by the script.
- Offer guidance for post-installation steps and troubleshooting.
- Explain the script's internal workings for those who want to contribute or adapt it.

Whether you are a new developer at Badal-IO or someone looking to fork this project for your own organization, this site is your central resource for understanding and using the script effectively.
