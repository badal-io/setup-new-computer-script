# Setup a New Developer Computer

This script will help with the quick setup and installation of tools and applications for new developers at Badal-IO. It is designed for macOS and works on both Intel and Apple Silicon machines.

## Documentation

For detailed information on what this script installs, how to use it, and how to customize it, please see our full documentation site:

[**View the full documentation**](https://badal-io.github.io/setup-new-computer-script/)

## Quick Install Instructions

Paste the command below in a Mac OS Terminal:
```shell
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/badal-io/setup-new-computer-script/main/setup-new-computer.sh)"
```

## Development

This repository contains a Docusaurus-based documentation site in the `/docs` directory. To run it locally:

1.  Navigate to the `/docs` directory: `cd docs`
2.  Install dependencies: `npm install`
3.  Start the local server: `npm start`
