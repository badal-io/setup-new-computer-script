# Setup New Computer Script

This repository contains a set of shell scripts for automating the setup of a new developer's computer on macOS. It is primarily designed for developers at Badal-IO, but it can be easily forked and adapted for other organizations.

## Quick Install

To run the setup script, paste the following command into your macOS Terminal:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/badal-io/setup-new-computer-script/main/setup-new-computer.sh)"
```
